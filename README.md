# upstream_a

Bottom of the three-package chain in the `upstream` distribution of the
[REP 159](https://github.com/openrobotics/reps/pull/32) test harness:
`upstream_a` ◄ `upstream_b` ◄ `upstream_c`. Counts the elements of an XML
document with libxml2. Plain CMake package, no ROS dependency.

Index and distribution files: https://github.com/rep159-testing/rep159-rosdistro
